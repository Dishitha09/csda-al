ISIC 2019 ACTIVE LEARNING — ANTIGRAVITY STARTER BUNDLE
====================================================

1. Extract ISIC2019_Antigravity_Starter_Bundle.zip into a workspace folder.
2. Open that extracted folder as your Antigravity project/workspace.
3. Open ANTIGRAVITY_MASTER_PROMPT_ISIC2019.md, copy the FULL prompt, and paste it into Antigravity Agent mode.
4. Prefer a system with an NVIDIA GPU, ample disk space and Internet access for full experiments.
5. The original ISIC 2019 images are NOT inside this ZIP and MUST be obtained from the official ISIC Archive, with the correct license terms.
6. The supplied PDF contains an older scope definition (excludes transfer learning/stopping); the new master prompt deliberately follows the newer slide and includes them.
7. The audio file is provided as an input artifact; transcription still needs to be attempted by Antigravity. Its contents were not independently transcribed here.
8. Do not mistake code/architectures/paper results for measured experimental results. Full model training must actually run on real ISIC 2019 data.

Official dataset: https://challenge.isic-archive.com/data/
Primary paper A: https://openaccess.thecvf.com/content/WACV2022/html/Bengar_Class-Balanced_Active_Learning_for_Image_Classification_WACV_2022_paper.html
Primary paper B: https://arxiv.org/abs/2210.01520

The uploaded archives, 9-page prior report, slide and audio are under inputs/.
